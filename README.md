so now we finally get to talk about the actual thing i made, the QT20

the QT20 is a 3 axis SCARA robot arm designed around external control and SG90 micro servos. it uses a rope tendon to actuate the claw, a rack and pinion to drive the vertical axis, and direct connections to servos for the rest of the joints.

i have not manufactured or assembled any parts yet, so i do not know if there are any issues with the design.
